# Sohel Matubber — Academic Portfolio

A responsive, static academic portfolio for Sohel Matubber, an Electrical and Electronic Engineering undergraduate at Jamalpur Science & Technology University.

## Preview locally
1. Extract the complete ZIP package.
2. Keep `index.html`, `assets/`, and `documents/` together in the same folder.
3. Open `index.html` in Chrome, Edge, Firefox, or Safari.

The page uses Tailwind CSS via its CDN and Google Fonts. An internet connection is required for those external styling/font resources. The local HTML, portrait, CV, favicon, and certificate files are packaged in this folder.

## Editing
Open `index.html` in VS Code. The `PORTFOLIO_DATA` object near the end of the file contains the editable profile, research, experience, certificate, and skills content.

## Deploy with GitHub Pages
1. Sign in to GitHub and create a new public repository (for example, `sohel-matubber-portfolio`).
2. Upload the complete contents of this folder, not the ZIP itself. Ensure `index.html` is at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the generated website URL shown in the Pages settings.

## Before public launch
- Confirm the final research title and conference wording against the conference programme/certificate.
- Check that all certificate files are intended for public display.
- Verify the phone number is suitable for public contact.
- Add a custom domain only after purchasing/configuring it with your DNS provider.
